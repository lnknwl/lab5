# Требования

Задание: https://aleksandr-003.github.io/labs/OOP_z/Labs1_5.html

Общие требования: https://aleksandr-003.github.io/labs/OOP_z/OOP.html

В пятой работе нет отдельных вариантов. Используется третья работа, в которой у меня вариант 4 — комплексное число

| Требование | Выполнение |
| --- | --- |
| Взять классы из лабораторной №3 | Скопированы Complex и Calculator |
| Разделить объявления и определения классов | include/Complex.h, include/Calculator.h и соответствующие src/*.cpp |
| Собрать статическую библиотеку | build/static/liblab3.a |
| Собрать динамическую библиотеку | build/shared/lab3.dll и библиотека импорта lab3.lib |
| Два клиента с одинаковым кодом | clients/main.cpp и tests/Tests.cpp используются для обоих exe |
| Разная линковка клиентов | Первый связан с liblab3.a, второй с lab3.lib и использует lab3.dll |
| Прямые вызовы компилятора | Команды g++ и ar в build.bat и описании сборки |
| Без автоматических систем сборки | Нет make, CMake и Ninja |
| Git с осмысленными коммитами | Изменения должны фиксироваться отдельными осмысленными коммитами |
| Doxygen | Комментарии к классам и функциям, Doxyfile и страницы документации |
| PlantUML | Диаграмма классов и схема двух способов подключения |
| Понимание кода | Описаны экспорт, импорт, линковка и назначение файлов |

В задании написано «иерархию классов», но прямо указана лабораторная №3. Поэтому взяты ее классы, без добавления наследования из четвертой работы
